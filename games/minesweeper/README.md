# Сапёр — Динамитная долина

Выберите «Сапёр» в общем меню, затем сложность, размер и «Начать игру».
Клетки и доска имеют квадратные пропорции при шрифте терминала 1:2,
например 8×16 пикселей на символ. Две символьные колонки соответствуют одной
строке по высоте. Масштаб выбирается максимально возможным в игровой области.
Все клетки одной доски одинаковые, поле центрируется. Рамка и промежутки
также учитывают пропорции шрифта.

| Поле | Клетка, столбцы × строки |
| --- | ---: |
| 8×8 | 8×4 |
| 10×10 | 6×3 |
| 12×12 | 4×2 |
| 14×14 | 4×2 |
| 16×16 | 4×2 |

Для игры нужно окно терминала 100×44 символа. Клетки заполнены целиком.
Разделители используют те же символы линий, что и рамка. Точки и цифры центрированы
с округлением до ближайшего символьного столбца и строки.
Вся площадь клетки, включая разделитель, реагирует на мышь.

Количество динамитов зависит от размера поля и сложности.

| Размер | Лёгкая | Средняя | Сложная |
| --- | ---: | ---: | ---: |
| 8×8 | 6 | 10 | 13 |
| 10×10 | 10 | 15 | 20 |
| 12×12 | 14 | 22 | 29 |
| 14×14 | 20 | 29 | 39 |
| 16×16 | 26 | 38 | 51 |

Стрелки двигают курсор. ЛКМ, Enter и пробел открывают клетку. ПКМ и F ставят
и снимают красную бандану на закрытой клетке. Бандана защищает её от открытия.
Первое открытие безопасно. Пустая область раскрывается вместе с числовой границей.
При наведении на открытую цифру подсвечиваются её закрытые соседи.
Когда число соседних бандан совпадает с цифрой, подсветка становится золотистой.
Нажмите на цифру, чтобы раскрыть остальных соседей. Ошибочная отметка
может привести к взрыву. Для победы откройте все безопасные клетки.
Каждая впервые открытая безопасная клетка приносит одно очко, в том числе при
раскрытии области. Новое поле начинается с нуля. При повторе «Цена ошибки»
пересчитывается с воспроизведённого первого хода.

Таймер запускается с первого открытия и останавливается на паузе и после
завершения партии. P ставит игру на паузу, Q возвращает в меню. R воспроизводит
раскладку и первый ход, а после победы на уровнях 1–4 оболочка предлагает
следующий размер. C копирует текущий P2 после первого открытия в Windows.
Код P2 можно ввести через пункт «Играть по коду».

Победа отмечается надписью «Поле зачищено», поражение — «Не заметил растяжку». После победы и поражения кнопка
«Посмотреть все поле» показывает все динамиты и числа. Правильные отметки
сохраняют бандану, ошибочные помечаются восклицательным знаком.
Кнопка «Начать заново» на обоих экранах начинает партию того же размера
и сложности с другим seed. Новый код P2 появится после безопасного первого хода.

Класс `Minesweeper` реализует пять методов `Game`. Для прежнего seed и первого
хода частичное перемешивание кандидатов даёт ту же раскладку. Очередь раскрытия
хранит только найденные нулевые клетки. Координаты мыши модуля уже локальны.
Вся плитка, включая края и шов, относится к одной логической клетке.

## Проверка

В корне проекта в терминале ESP-IDF v5.5.1 соберите прошивку и запустите тест.

```powershell
idf.py -DIDF_TARGET=esp32 build
python games/minesweeper/tests/qemu_check.py
```

Тест использует клавиши, мышь и известную раскладку. Он проверяет клики по краям
клеток, красные банданы, счёт, воспроизведение по коду, повтор, быстрое раскрытие,
оба исхода, просмотр поля и появление нового ключа после перезапуска.

Для проверки механики на компьютере с GCC выполните из корня в Bash:

```bash
mkdir -p build-host
g++ -std=c++17 -Wall -Wextra -Werror -I common -I games/minesweeper \
  games/minesweeper/tests/mechanics.cpp games/minesweeper/minesweeper.cpp \
  common/{screen,menu,code}.cpp -o build-host/minesweeper-mechanics
./build-host/minesweeper-mechanics
```

Общий `tools/smoke.py` из базового коммита проверяет надпись старой заглушки
в игровой области. Для проверки Сапёра используйте сценарий этого модуля.
