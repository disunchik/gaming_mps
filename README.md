# Промпт, паяльник, три ствола

Тетрис, сапёр и пин-понг для ESP32. У каждой игры есть уровни и выбор сложности. Изображение выводится в цветной терминал. Разверните окно минимум до **100×44 символов**.

## Запуск на ESP32

Установите ESP-IDF **5.5.1** и откройте его терминал. Подключите плату по USB. Номер COM-порта посмотрите в диспетчере устройств.

```powershell
git clone https://github.com/disunchik/gaming_mps.git
cd gaming_mps
idf.py -p COM5 flash
python tools/run.py --port COM5
```

Вместо `COM5` укажите свой порт. Запускатель подключается к уже прошитой плате. Если порт занят, закройте IDF Monitor или другую программу, которая его использует. Для выхода — **F10** или **Ctrl+]**.

## Запуск без платы

В терминале ESP-IDF установите QEMU:

```powershell
python "$env:IDF_PATH/tools/idf_tools.py" install qemu-xtensa
```

Откройте новый терминал ESP-IDF, перейдите в папку проекта и выполните:

```powershell
python tools/run.py
```

На Windows можно запускать через `Run-QEMU.cmd`.

## Управление

- **Меню:** стрелки или WASD. Enter — выбрать. В настройках ←/→ меняют значение.
- **Тетрис:** ←/→ — сдвиг, ↑ — поворот, ↓ — ускорить падение.
- **Сапёр:** ЛКМ / Enter / пробел — открыть клетку, ПКМ / F — поставить бандану. Стрелки перемещают курсор.
- **Пин-понг:** держите ←/→ или A/D либо двигайте мышью.
- **Во время игры:** P — пауза, R — повтор тех же условий, Q / Esc — в меню, C — скопировать код.

Подробнее о заказах, раскрытии соседних клеток и бонусной дуэли — в пункте **«Краткая сводка»**.

## Игра по коду

Выберите «Играть по коду». Введите P2 вручную или нажмите **↑ / Ctrl+V**, чтобы вставить его из буфера, затем Enter. Код повторяет стартовые условия партии.

Вставка, копирование, мышь и управление в русской раскладке работают через наш запускатель — и в QEMU, и при подключении к COM-порту. В обычном IDF Monitor используйте английскую раскладку; вставка зависит от терминала, код можно набрать вручную.
