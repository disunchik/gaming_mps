# Промпт, паяльник, три ствола

Тетрис, сапёр и пин-понг для ESP32. У каждой игры есть уровни и выбор сложности. Изображение выводится в цветной терминал. Разверните окно минимум до **100×44 символов**.

## Запуск на ESP32

Установите ESP-IDF **5.5.1** и откройте его терминал. Подключите плату по USB. Номер COM-порта посмотрите в диспетчере устройств.

```powershell
git clone https://github.com/disunchik/gaming_mps.git
cd gaming_mps
idf.py -p COM5 flash
python tools/run.py --port COM5
```

Вместо `COM5` укажите свой порт. Запускатель подключается к уже прошитой плате. Если порт занят, закройте IDF Monitor или другую программу, которая его использует. Для выхода — **F10** или **Ctrl+]**.

## Запуск без платы

Нужны установленный ESP-IDF **5.5.1 с инструментами ESP32** и `qemu-xtensa`.
GCC, CMake, Ninja и Python поставляются вместе со средой ESP-IDF;
отдельно устанавливать их для этого проекта не нужно. Git нужен для клонирования.
VS Code для запуска игр не требуется.

Откройте **терминал ESP-IDF**, а не обычный PowerShell или Bash. Установите QEMU:

```powershell
python "$env:IDF_PATH/tools/idf_tools.py" install qemu-xtensa
```

Откройте новый терминал ESP-IDF, перейдите в папку проекта и выполните:

```powershell
python tools/run.py
```

На Windows `Run-QEMU.cmd` сам собирает проект и запускает игру. Он находит
ESP-IDF, установленный через EIM, либо использует уже активную среду ESP-IDF.
Поэтому на другом компьютере надёжный порядок — открыть терминал ESP-IDF,
перейти в папку свежего клона и выполнить `python tools/run.py`.
Одна установка SDK без активации его среды не добавляет команды в обычный терминал.

## Отладка в VS Code

Нужно расширение **C/C++ от Microsoft** (`ms-vscode.cpptools`).
Откройте всю папку проекта в VS Code.

1. Один раз запустите `Configure-VSCode.cmd`. В среде, установленной без EIM,
   запускайте его из терминала ESP-IDF. Он сам найдёт GDB и создаст локальный launch.json.
2. Откройте `main/main.cpp`. В «Запуск и отладка» выберите **ESP32 / QEMU** и нажмите F5.
3. Дождитесь активации среды и сборки. Программа остановится в `app_main`.
4. F9 ставит точку останова на выбранной строке, F10 выполняет следующую строку,
   F5 продолжает выполнение. Shift+F5 завершает сеанс и закрывает его QEMU.

Для VS Code используются отдельные порты 5558/3334. Ручная отладка использует
5555/3333. Конфигурация с локальным путём GDB не входит в Git: на чужом компьютере
её создаёт тот же Configure-VSCode.cmd, без путей с компьютера автора.

## Управление

- **Меню:** стрелки или WASD. Enter — выбрать. В настройках ←/→ меняют значение.
- **Тетрис:** ←/→ — сдвиг, ↑ — поворот, ↓ — ускорить падение.
- **Сапёр:** ЛКМ / Enter / пробел — открыть клетку, ПКМ / F — поставить бандану. Стрелки перемещают курсор.
- **Пин-понг:** держите ←/→ или A/D либо двигайте мышью.
- **Во время игры:** P — пауза, R — повтор тех же условий, Q / Esc — в меню, C — скопировать код.

Подробнее о заказах, раскрытии соседних клеток и бонусной дуэли — в пункте **«Краткая сводка»**.

## Игра по коду

Выберите «Играть по коду». Введите P2 вручную или нажмите **↑ / Ctrl+V**, чтобы вставить его из буфера, затем Enter. Код повторяет стартовые условия партии.

Вставка, копирование, мышь и управление в русской раскладке работают через наш запускатель — и в QEMU, и при подключении к COM-порту. В обычном IDF Monitor используйте английскую раскладку; вставка зависит от терминала, код можно набрать вручную.
